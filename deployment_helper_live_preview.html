Free Hosting Guide

How to put your website live in 3 minutes

Since your website code is fully self-contained in a single index.html file, hosting it online for free is fast and straightforward. Choose your platform below to follow interactive steps.

Netlify Drop Walkthrough (1-Minute Setup)

No account required to test
1

Save your website file

Create a new folder on your computer named my-indeed-ad and save the HTML code block above as index.html inside that folder.

2

Open Netlify Drop

Navigate to app.netlify.com/drop in a new tab.

3

Drag and drop folder

Drag your my-indeed-ad folder into the dashed target box on Netlify's page.

4

Get your live URL

Netlify will generate a live SSL link (e.g. https://cool-site-1234.netlify.app). You can share this link immediately!

GitHub Pages Walkthrough

Free GitHub account required
1

Create a GitHub Repository

Log in to GitHub and click New Repository. Name it uber-eats-job-ad and make it Public.

2

Upload index.html

Click Creating a new file, set the filename to index.html, paste your HTML code into the editor, and click Commit Changes.

3

Enable GitHub Pages

Go to repository Settings → Pages. Under Branch, select main branch and click Save.

4

Access Published Page

In ~1-2 minutes, your website will be live at https://<username>.github.io/uber-eats-job-ad/.

Vercel Walkthrough

Free Vercel account required
1

Sign up at Vercel

Go to vercel.com and sign in using your GitHub account.

2

Import Repository

Click Add New Project → Select your GitHub repository containing index.html.

3

Deploy

Click Deploy without changing default settings. Vercel automatically detects static HTML and hosts it globally with low latency.

Ready to deploy?
